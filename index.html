Passive & RAF Optimized

          

            All pointer and scroll events use passive event listeners to prevent main-thread jank. Pointer tracking coordinates are cached and applied strictly in requestAnimationFrame ticks.
          

        

        

          
IntersectionObserver Only

          

            Scroll reveal does not poll scroll position or attach costly scroll listeners. The native browser IntersectionObserver API detects element visibility asynchronously with minimal overhead.
          

        

        

          
Auto-Paused on Inactive Tabs

          

            When the user changes browser tabs or minimizes the window, AuraFX monitors document.visibilityState and halts all animation loops immediately to eliminate background CPU/battery drain.
          

        

      

    

  


  
  

    

      

        Developer Reference
        
Documentation & Guides

        
Everything you need to integrate AuraFX into any project.

      


      
      

        
        
        
        
        
      


      
      

        

          
1. Installation

          
Install AuraFX from npm using your package manager of choice:

          

            npm install aurafx
            
          


          
2. Simplest Activation

          
Import and call initAura() in your app entry point:

          

            import { initAura } from 'aurafx';

initAura();
            
          


          
3. HTML Only Activation

          
Once initialized, apply effects simply by adding data attributes to your HTML elements:

          

            <button data-aura-magnetic data-aura-glow data-aura-ripple>Click Me</button>
            
          

        

      


      
      

        

          
HTML Attribute Reference

          
Declarative data attributes automatically detected by the engine:

          

            
              

                Attribute
                Values / Type
                Description
              

            
            
              

                data-aura
                "fade-up" | "fade-down" | "fade-in" | "slide-left" | "slide-right" | "scale-in" | "blur"
                Triggers scroll reveal animation when element enters the viewport.
              

              

                data-aura-delay
                number (ms) (e.g. "200")
                Delay before scroll reveal animation begins.
              

              

                data-aura-duration
                number (ms) (e.g. "800")
                Duration of the reveal transition.
              

              

                data-aura-distance
                string (CSS distance) (e.g. "40px")
                Distance translated during fade or slide reveals.
              

              

                data-aura-stagger
                number (ms) on parent container
                Automatically staggers reveals of child [data-aura] elements.
              

              

                data-aura-magnetic
                Boolean attribute
                Attracts element subtly toward cursor on hover.
              

              

                data-aura-magnetic-strength
                number (0.1 - 0.6)
                Adjusts magnetic pull intensity.
              

              

                data-aura-glow
                Boolean attribute
                Adds mouse-following radial perimeter and surface glow.
              

              

                data-aura-glow-color
                hex / rgba (e.g. "#8b5cf6")
                Custom color for interactive glow.
              

              

                data-aura-ripple
                Boolean attribute
                Adds click ripple wave originating from pointer coordinates.
              

              

                data-aura-tilt
                Boolean attribute
                Enables 3D perspective tilt on hover with light glare reflection.
              

              

                data-aura-tilt-angle
                number (degrees) (e.g. "12")
                Maximum tilt rotation angle.
              

            
          

        

      


      
      

        

          
Full Configuration Schema

          
Pass any subset of options to initAura(options):

          

            
initAura({
  cursor: {
    enabled: true,
    color: '#8b5cf6',
    ringColor: 'rgba(139, 92, 246, 0.45)',
    dotSize: 7,
    ringSize: 34,
    trail: true,
    trailLength: 12,
    particles: false,
    glow: true,
    spotlight: false,
    lerp: 0.18,
    disableOnTouch: true
  },
  scroll: {
    enabled: true,
    defaultEffect: 'fade-up',
    duration: 700,
    distance: '28px',
    threshold: 0.15,
    once: true,
    stagger: 80
  },
  ambient: {
    enabled: false,
    intensity: 'low', // 'low' | 'medium' | 'high' | number
    palette: 'cyber-violet', // preset or string[]
    speed: 0.4,
    blur: 90,
    particles: true
  },
  magnetic: {
    enabled: true,
    strength: 0.28,
    maxDistance: 32,
    scale: 1.0
  },
  glow: {
    enabled: true,
    color: '#8b5cf6',
    intensity: 0.35,
    radius: 260
  },
  ripple: {
    enabled: true,
    color: 'rgba(255, 255, 255, 0.35)',
    duration: 600
  },
  tilt: {
    enabled: true,
    maxAngle: 8,
    perspective: 1000,
    scale: 1.02,
    glare: true
  },
  injectStyles: true,
  reducedMotion: 'respect' // 'respect' | 'ignore'
});

          

        

      


      
      

        

          
React & Next.js

          
Call initAura() inside a top-level client component or hook:

          

            
'use client';
import { useEffect } from 'react';
import { initAura } from 'aurafx';

export default function RootLayout({ children }) {
  useEffect(() => {
    const aura = initAura();
    return () => aura.destroy();
  }, []);

  return <html><body>{children}</body></html>;
}

          


          
Vue 3

          
Mount in your App.vue component:

          

            
<script setup>
import { onMounted, onUnmounted } from 'vue';
import { initAura } from 'aurafx';

let aura;
onMounted(() => {
  aura = initAura();
});
onUnmounted(() => {
  aura?.destroy();
});
</script>

          

        

      


      
      

        

          
Controller API

          
The controller returned by initAura() provides complete runtime control:

          

            
              

                Method
                Signature
                Description
              

            
            
              

                aura.destroy()
                () => void
                Removes all DOM elements, styles, event listeners, and observers.
              

              

                aura.refresh()
                () => void
                Scans for newly added DOM elements and connects effects.
              

              

                aura.enable(name)
                (effect: AuraEffectName) => void
                Dynamically activates a specific effect.
              

              

                aura.disable(name)
                (effect: AuraEffectName) => void
                Dynamically disables and cleans up a specific effect.
              

              

                aura.toggle(name, val?)
                (effect: AuraEffectName, enabled?: boolean) => void
                Toggles state of an effect.
              

              

                aura.updateConfig(opts)
                (newOptions: Partial<AuraOptions>) => void
                Updates configuration parameters live on the fly.
